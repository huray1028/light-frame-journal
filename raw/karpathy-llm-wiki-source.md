# Andrej Karpathy — LLM Wiki

本檔保存來源資訊，不取代原始 Gist。專案使用的核心觀念是：讓 LLM 持續維護一個由 Markdown 組成、互相連結、可追溯來源的知識庫，使新來源能更新既有概念、指出矛盾並累積理解，而不是每次查詢都重新從原始文件拼湊答案。
